# Aviation Ground School Academy — independent deployment

## Step 1 — Create an independent GitHub repository
1. Sign in at https://github.com/new
2. Owner: magnusclarkson-star
3. Repository name: aviation-ground-school-academy
4. Choose Private while developing (GitHub Pages availability depends on plan), or Public for straightforward free GitHub Pages hosting. **Public means the code and assets are visible to everyone.**
5. Do not initialize with a README, .gitignore or license.
6. Select Create repository.

## Step 2 — Upload the files
1. Open the new repository, select 'uploading an existing file'.
2. Extract this ZIP on a computer. Upload the CONTENTS of the aviation-academy-github-ready folder to the repository root (not the enclosing folder). The .github workflow is a hidden directory; ensure it is included. If the browser uploader cannot include hidden folders, use GitHub Desktop or Git.
3. Commit the files to main.

## Step 3 — Enable GitHub Pages
1. Repository > Settings > Pages.
2. Under Build and deployment, Source: GitHub Actions.
3. Open Actions and wait for 'Deploy Academy to GitHub Pages' to succeed.
4. Visit https://magnusclarkson-star.github.io/aviation-ground-school-academy/

## Important boundaries
- This is a STATIC preview only. Local browser storage is not secure user authentication or a shared database.
- Do not enter real payment API keys, student personal data or guardian documents into this preview.
- Do not enable live subscription charging, child-to-adult messaging, public uploads or advertising before building and reviewing the backend and safeguarding features.
- GitHub Pages does not provide a private backend or protected membership access. Public Pages sites can be viewed by anyone with the link.
- The academy must remain separate from the Salone One repository and deployment environment.
